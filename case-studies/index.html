02 // Proof of Work

Translate the magic into evidence.

These case studies explain the problem, the build, the current proof, and the next upgrade for the systems orbiting Aetherhaven.

Dockmaster + Forge Fuel

Problem: Aetherhaven had a strong identity, but visitors needed a guide. Build: a static-safe command deck with slash commands, project routing, issue drafts, devlogs, contact drafts, and a temporary Forge Fuel UI. Status: draft-only MVP in PR. Next: hook into homepage and add private backend later.

Pet Grave

Problem: the game has emotional power but needs a clearer first-time loop. Build direction: title screen, gentle tutorial, memory-grave interactions, ghost-pet idle behaviors, ambient sound, and a polished vertical slice. Next: use Dockmaster to generate v0.3 issues.

AetherBrowser

Problem: normal browsers feel passive and platform-owned. Vision: a sovereign browser where AI, privacy, context, and command-center workflows are native. Proof: flagship repo direction. Next: screenshots, architecture notes, and a 60-second tour.

Clawd / Openclaw

Problem: AI coding work loses context across tools. Vision: local project-aware workflows that turn ideas into tasks, patches, and reviewable handoffs. Next: connect the story to Aetherhaven as the developer-tooling bay.
