04 // Forge Fuel

Bring temporary fuel. Leave no trace.

Forge Fuel is the permissioned enhancement chamber for Aetherhaven projects. Choose a project, choose a mission, set boundaries, and generate draft-only output you can review before anything happens.

Open Forge FuelRead architecture
1 // Choose project

Select the dock.

Pet Grave, AetherBrowser, Aetherhaven, Ghostline, MIST, Clawd, or a custom project brief.

2 // Choose mission

Lock the run.

Project triage, GitHub issue drafts, README polish, devlog, roadmap, code-review checklist, or demo polish.

3 // Set limits

Permission gates stay visible.

The public MVP drafts only. Repo writes, pull requests, messages, and merges stay disabled until a private approval layer exists.

Current MVP

Static-safe by default.

The current Forge Fuel module runs in demo mode on GitHub Pages. It can collect a brief, simulate a draft run, produce a project plan, and export Markdown. A future server-side runner can support real model calls without exposing secrets in static code.
