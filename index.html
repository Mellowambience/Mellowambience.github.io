01 // About

Half engineer, half world-builder.

Everything on this page is something I actually built — prototypes that turned into products, ideas that became systems, experiments that became worlds. The through-line: AI should be private, local-first, and genuinely useful, not a chatbot locked inside someone else's server.

I work across full-stack engineering, AI systems, browser tooling, security research, and game design. If it sounds strange, that's the point — I build the things mainstream tools haven't caught up to yet.
