## What's inside

  11 sprites: forager, trader, builder, scout, curator, you, berry, crystal, spellbook, tile, flower.
- `modules/driftkin/` — a *real, runnable* founder species (register.py + demo.html) you can
  study as a reference for agentic NPC behavior in your own game.
- `ugc_pack.json` — manifest + license + slice instructions.

## How to drop it in
**Roblox:** import `spritesheet.png` as a Decal/ImageLabel; slice the 4-col atlas at 64x64.
**Fortnite (UEFN):** import as a Texture; use a Sprite/RetainerBox with 64x64 cells.
**Any engine:** the PNGs are standard RGBA — use as you would any sprite sheet.
